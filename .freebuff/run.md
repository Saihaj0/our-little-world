# Our Little World — run doc

Private Next.js 15 (App Router) site. Password-gated via middleware + HMAC session cookie.

## 1. Reproduce uncommitted artifacts (fresh checkout)

1. **Env file** — copy `.env` from the main checkout into this workspace (copy, don't symlink).
   It must define `SITE_PASSWORD` (min 8 chars) and `SESSION_SECRET` (min 32 chars);
   see `.env.example` for the template. Without it every route 307-redirects to `/welcome`
   and login returns 503.
2. **Dependencies** — `npm install` (lockfile: `package-lock.json`; package manager: npm).
3. No other build artifacts are needed; `.next/` is generated by the dev server.

## 2. Run the dev server

```sh
npm run dev          # next dev, default port 3000
```

- Open http://localhost:3000 — middleware redirects to `/welcome` (the lock screen).
  Enter `SITE_PASSWORD` to unlock; the site renders at `/`.
- Detached start on Windows (survives the terminal):
  `powershell -NoProfile -Command "(Start-Process -FilePath 'npm.cmd' -ArgumentList 'run','dev' -RedirectStandardOutput '<log>' -RedirectStandardError '<log>.err' -WindowStyle Hidden -PassThru).Id"`
  (stdout and stderr must go to different files.)
- If you see bizarre runtime errors from a stale build (e.g. `Math.random is not a
  function` inside `AmbientBackground`), stop all `node …next…start-server.js` processes,
  `rm -rf .next`, and restart.

## Bucket-list persistence (localStorage)

The "Someday list" section keeps additions/deletions in `localStorage` under
`olw:bucket-list:v1` — shape `{ done: string[], custom: {id,title,category}[], deleted: string[] }`.
Deleting a built-in item records its id in `deleted`; deleting a custom item removes it
from `custom`. Per-browser only; clearing site data resets the list.
